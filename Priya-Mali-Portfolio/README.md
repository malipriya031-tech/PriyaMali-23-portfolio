# Priya Mali — Software Developer Portfolio

One-folder portfolio package containing the portfolio, approved resume, RentWear and Scary Gift projects.

## Structure
- `index.html` — portfolio home and sections
- `style.css` / `script.js` — portfolio styling and interactions
- `resume.pdf` — approved Software Developer resume
- `projects/rentwear/` — RentWear demo
- `projects/scary-gift/` — Scary Gift demo
